# Website Places Media

This folder contains location-organized media for a website Places section.

- Use `places-manifest.json` as the canonical index.
- Filenames are descriptive and URL-safe.
- Exact landmark names are used only when reasonably confident.
- `capture_date` is date-only (`YYYY-MM-DD`); times are intentionally omitted.
- Dates come from user-provided Apple Photos screenshots or explicit user-provided dates because the uploaded media copies generally have stripped EXIF capture dates.
- Do not infer missing dates from filesystem modification times or video container creation times; those can reflect upload/export processing rather than original capture.
